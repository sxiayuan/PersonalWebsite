package.json: the project’s control panel.
Jargon: manifest (a file listing project info, scripts, dependencies).

package-lock.json: the exact versions list of every installed package, so everyone installs the same thing.
Jargon: dependency lockfile.

next.config.mjs: settings for how Next.js runs and builds.
Jargon: framework config.

tsconfig.json: rules for TypeScript checking/compiling your code.
Jargon: compiler options.

next-env.d.ts: helper type file Next.js creates so TypeScript understands Next features.
Jargon: type declarations (.d.ts).

postcss.config.js: instructions for CSS tools that transform your CSS before browser sees it.
Jargon: PostCSS pipeline and plugins.

tailwind.config.js: your Tailwind customization file (colors, where to look for classes, theme extensions).
Jargon: design tokens and content paths.

eslint.config.mjs: code quality rules (style + common bug checks) in the new format.
Jargon: linter config / flat config.

.eslintrc.json: older version of ESLint config format.
Jargon: legacy config.

.gitignore: “do not track these files in Git” list.
Jargon: ignore patterns.

PROJECT_SETUP.md: setup guide for humans (how to run/build project).
Jargon: project documentation.

context.MD: vision/creative direction doc (what the site should feel like and communicate).
Jargon: product/design context.
